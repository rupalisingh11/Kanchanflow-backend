# KanchanFlow Backend

Spring Boot REST API for the KanchanFlow manufacturing CRM website.

## Technologies Used
- Java 21
- Spring Boot 3.5.4
- Maven
- Docker
- REST API

## Features
- Backend health monitoring
- REST API endpoint
- Frontend and backend integration
- Docker-based deployment

## API Endpoint

GET `/api/v1/health`

Response:
```json
{
  "status": "UP",
  "message": "KanchanFlow backend is running"
}
